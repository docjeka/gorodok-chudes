# Маленький город чудес

Игра-песочница для ребёнка: кукольный дом, шесть героев, наряды, готовка, питомцы, подарки. Без проигрыша, рекламы, покупок, аккаунтов и сбора данных. Веб-приложение (PWA) для планшета: после первой загрузки работает без интернета.

Состояние: **этап B** — первая версия, в которую можно играть. Что готово и что запланировано — в `docs/CONTENT_CHECKLIST.md`, как проверено — в `docs/TEST_REPORT.md`.

## Команды

Нужен Node.js 20+ (проверено на 22).

```bash
npm install          # зависимости
npm run dev          # разработка: http://127.0.0.1:5173
npm test             # тесты правил игры (Vitest)
npm run build        # production-сборка в dist/
npm run preview      # сборка на http://127.0.0.1:4173 (с сервис-воркером)
npm run test:e2e     # браузерные сценарии (нужен Chrome; путь можно задать в CHROME)
node scripts/capture.mjs all   # снимки сцен в .studioigor/captures/
```

## Как открыть на планшете

`localhost` и `127.0.0.1` — это адрес самого компьютера: на планшете он не откроется.

1. Соберите игру: `npm run build`. Папка `dist/` — это весь сайт, сервер и база данных не нужны.
2. Выложите содержимое `dist/` на любой статический хостинг с **HTTPS** (свой сервер, GitHub Pages, Netlify, Cloudflare Pages и т. п.). Установка на главный экран и работа без интернета требуют HTTPS — это требование браузеров, обойти его отключением защиты нельзя и не нужно. Выбор хостинга и публикация — ваше решение; игра сама ничего не публикует.
3. Откройте ссылку на планшете и дождитесь загрузки. В «Настройки → Для родителей» появится строка «Готово к игре без интернета».

Для быстрой пробы в домашней сети можно запустить `npx vite preview --host` и открыть `http://<адрес компьютера>:4173` — играть получится, но установка и офлайн по обычному HTTP работать не будут.

## Установка на главный экран

- **iPad, Safari:** «Поделиться» → «На экран Домой».
- **Android, Chrome:** меню → «Установить приложение» или «Добавить на главный экран».

Это веб-приложение, а не приложение из App Store или Google Play.

## Резервная копия

Мир хранится только в браузере планшета (IndexedDB). Очистка данных сайта, приватный режим или нехватка места могут его удалить — это не облачная копия.

«Настройки» → удерживать «Для родителей» → **«Сохранить копию мира в файл»**. Файл `gorodok-chudes-ГГГГ-ММ-ДД-ЧЧММ.json` можно загрузить обратно кнопкой «Загрузить мир из файла». Повреждённый файл игра отклонит и текущий мир не тронет.

## Как устроено

- `src/game` — модель мира и правила (владение вещами, руки, контейнеры, рецепты, подарки, одежда). Чистые функции без DOM — тестируются напрямую.
- `src/content` — каталоги: предметы, мебель, комнаты, костюмы, реплики, манифесты спрайтов.
- `src/scene` — сцена PixiJS, которая каждый раз строится из модели; ввод; взаимодействия; реплики.
- `src/ui` — панели на HTML/CSS; `src/storage` — сохранения и офлайн; `src/audio` — музыка и звуки (синтез); `src/i18n` — русский и английский.
- `scripts/` — подготовка ассетов: `slice.py` и `calib.py` (мебель, предметы, питомцы), `chars.py` (фигурки и точки лица), `gen-voice.py` (озвучка), `capture.mjs` (снимки).
- `art-src/user` — исходные листы картинок; `public/assets` — нарезанные спрайты.
- `.studioigor/` — журнал решений, концепт, реестр ресурсов (`ASSETS.md`).

### Новые фигурки героев

```bash
npx vite-node scripts/ref-chars.ts        # эталонные листы без лиц
python3 scripts/chars.py <лист.png> <колонок> <рядов> герой:костюм,герой:костюм
```
Каждая пара «герой:костюм» — две фигурки подряд: стоя, затем сидя. Нужен румянец на щеках: по нему скрипт находит лицо. Результат дописывается в `src/content/charSprites.json`, проверочная картинка с точками — в `.studioigor/captures/sheets/`.

## Нативная сборка (на будущее)

Упаковка через Capacitor возможна после веб-версии, но в этом этапе не делалась и по актуальной документации не сверялась. Для iOS понадобятся Mac с Xcode и платный аккаунт Apple Developer, для Android — Android Studio и ключ подписи; публикация в магазинах платная и проходит проверку. Перед началом сверьтесь с официальной документацией Capacitor, Apple и Google.

> В архив не вложены исходные листы картинок (`art-src/user/`, около 35 МБ) — это ваши собственные файлы. Они нужны только для повторной нарезки скриптами; игра и сборка работают без них.
