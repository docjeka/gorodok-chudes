# Дизайн — коротко

**Что это.** Цифровой кукольный дом. Ребёнок 5–9 лет (допущение) берёт героев и вещи пальцем и разыгрывает свои истории.

**Столпы.** Всё можно взять · Ничего не теряется · Мир отвечает мягко · Без давления · Понятно без чтения.

**Цикл.** «Играть» → последняя комната → позвать героя → нарядить → дать вещь или еду → перейти в другую комнату → закрыть → продолжить с того же места.

**Управление.** Перетаскивание после порога 9 px; альтернатива — «нажал вещь, нажал цель». Один активный перенос, второй палец игнорируется. Цель выбирается по положению вещи: рука или рот героя → питомец → корзина/коробка → поверхность или ящик → пол. Невозможный бросок возвращает вещь на место.

**Модель.** У каждой вещи один владелец: пол комнаты, поверхность, рука, ящик мебели, корзина/коробка, сумка или «найденные вещи». Сцена строится из модели, а не наоборот.

**Герои.** Шесть героев, у каждого четыре костюма; фигурка — готовая картинка стоя и сидя, лицо (глаза, брови, рот) рисуется кодом в точках спрайта — отсюда эмоции, моргание и движение рта.

**Изюминки (выбраны заказчиком).** Волшебная ночь (тёмное окно, свет ночника, сны спящих) · питомцы с характером (кот в корзине, собака несёт игрушку, кролик идёт за морковкой) · чудо-блюда из «неправильных» рецептов.

**Чего нет намеренно.** Таймеров, наград за вход, покупок, сети, чата, сбора данных, правильного сюжета.
